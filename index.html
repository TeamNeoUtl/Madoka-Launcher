Madoka Launcher

ゆっくりMovieMaker 4 / AviUtl（ExEdit0 / ExEdit2） 専用の、バージョン・プラグイン・インスタンス管理アプリ

Madoka Launcher 最新版をダウンロード

概要

動画編集ソフト本体及び拡張プラグインのダウンロードと整理を簡単に行えます。広告やトラッキング等は一切ありません。

複数のソフト管理

YMM4やAviUtlなどの複数バージョンをまとめて管理。

インスタンス管理

複数の実行環境を一箇所で作成、実行、削除。

非Windows対応

Windows 以外の環境でも快適に管理ツールを動作。

よくある質問

バージョン管理とは
動画編集ソフトウェア本体のインストール、更新、削除等を簡単に行えます。
インスタンス管理とは
複数の実行環境を一箇所で作成、実行、削除等できます。
プラグイン管理とは
プラグインや拡張等のインストール、更新、削除等を簡単に行えます。
Madoka Launcher は公式ですか
いいえ。Madoka チームは ゆっくりMovieMaker や AviUtl とは直接関係のない、有志による非営利チームです。
Windows 以外でも AviUtl や YMM4 を動作させられますか
Madoka Launcher は現在、Wine 等の互換レイヤーや QEMU 等のエミュレーターによる Windows 以外の OS における Windows 専用のソフトウェアを動作させる機能は搭載しておりません。

NeoUtl や Freya NLE は Linux や macOS に対応していますから、これらをご活用下さい。
プラグインや本体の更新をどの様に検出しているのですか

AviUtl については、既存のプラグインマネージャーと同じリポジトリを参照します。全ての対応ソフトウェアについて Madoka は独自のデータベースを持ちませんから、最新への追従が容易になっています。
